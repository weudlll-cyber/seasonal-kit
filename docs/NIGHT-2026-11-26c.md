# Night of 2026-11-26: shared ops parts for every game (install, operate, secure)

The unattended chain after the v0.28.0 release. Goal (owner, 2026-11-26): installing and running
any Seasonal game is very easy for the server's owner, very safe, and checked as far as possible.
What one game has and the others lack moves into the kit. One branch and one release per piece from
2 on; the sheet is pushed after every piece. Games and the website are read only.

Read at the start: Bingo Royale `d7d841e`, Mini Games `ae8fe40` (and `feat/kit-0.22` `a483d81`),
Seasonal Cases `0070e6b` (`kit/v0.17-adoption`), website `10c4619`.
