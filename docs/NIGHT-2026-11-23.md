## Piece 6: the season feed reader (DECISIONS K34)

  from the website's GAME-INTEGRATION §6 and `server/src/season/routes.js` (d4230af).

## Piece 7: RateLimiter with a rule read on every request (Bingo R3)

- **`RateLimiter(source, now, maxKeys)`:** `source` is a `RateRuleSource`, a rule or a function
  that gives one, as Bingo's at 5c613c0. A function is read on every `take`. One read rule
  serves the request: the refill, the cap (a lowered limit caps the buckets at once) and the
  forgetting of idle keys.
- **Unlike Bingo's, a bad rule never throws inside a request:** a broken rule given later, or a
  read that throws, keeps the last valid rule, so the limit never lifts. The first rule is
  checked at construction, as a fixed one is.
- **Tests:** src/server/rateRule.test.ts (new): lowered and raised limits; a new window; a
  broken later rule (0, NaN) and a throwing read; a broken first rule. The old
  guards.test.ts limiter tests pass unchanged. 100 % of rateLimit.ts.
