## Piece 2: ThemeToggle without `window` during render

`useTheme` starts from `null` (shown as light) and resolves the theme in a layout effect, before
the first paint; `<html data-theme>` is written only once it is known. A render never reads
`window` or storage, so server and first client render match. The new test renders the toggle
and the whole header with `renderToString` in Node; without the fix both throw
`ReferenceError: window is not defined` (checked).

- **Lines:** theme.tsx 90→108, server-render.test.tsx new 42, CHANGELOG.md 637→644.
- **Removed:** `useState(resolveTheme)`, the read during render.
- **Reused:** `resolveTheme`, `applyTheme` (../theme).
