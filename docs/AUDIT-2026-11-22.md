# Audit of 2026-11-22

A full audit of the kit at v0.9.0 (`087e5b0`), as DECISIONS K23 asks. Each of nine areas was
audited by its own fresh, independent agent. The auditors read the repository and did not change
it. The tests auditor worked in a private clone. Every finding below was then checked against the
code by the session that ran the audit, not taken on the auditor's word. The fixes are in v0.9.1
(PR from `fix/audit-2026-11-22`).

The rule for each finding:

- **Fixed:** it changes nothing a game or a player sees, or it is a fix to docs, tests, CI or
  comments.
- **Owner:** it would change what players see, a public API, the repository's GitHub settings,
  CLAUDE.md, or a legal question. It is listed under "Needs the owner's word".
- **Noted:** not a defect, or too small to act on now. It is kept here.

No area found a high-severity defect. The medium finding with a real effect was B1's redirect:
a route or header with a tab or newline passed the local-path check, and the URL parser then
dropped it, so `/\t/evil.example` led off the site. It is fixed in v0.9.1.

The tests auditor ran the whole suite 10 times in a row: 336 of 336 each time, no flaky test, no
worker failure, 100 % coverage. Of 14 sabotages of key rules, 10 were caught. Each of the four
it missed is closed in v0.9.1 or explained:

- the 2 KB cap on the steps header: a test now sends a valid header that is too long;
- a dead regex branch: removed;
- the detached-frame guard: now tested;
- `secretMatches`' two refusals of an empty secret: either one alone is enough, so no input
  separates them. This is defence in depth, not a gap.

## Needs the owner's word

In order of weight.

1. **The font's licence (B8).** The woff2 files' own `name` table reads "Copyright (c) 2021 by
   Fontastica. All rights reserved." It was checked by decompressing
   `fonts/luxora-grotesk-bold.woff2`. The docs (fonts/README.md, README.md, K8) say the font
   "belongs to the Seasonal Tokens project, which bought it". The repository is public, so
   anyone can download the files.
   - Does the licence the project bought allow publishing them in a public repository? If not,
     the fonts need another home. Removing them from history is a separate decision, since
     CLAUDE.md forbids rewriting history.
   - Either way, the docs should name Fontastica as the copyright holder.
   - A NOTICE file and SPDX lines in the headers are optional (B8 L1, L2).
2. **GitHub settings (B6, B9).** None changes the code. Each is a setting only the owner should
   change:
   - turn on `delete_branch_on_merge`;
   - allow merge commits only (squash and rebase are on, and a release needs a merge commit);
   - add a tag ruleset on `refs/tags/v*`: no update, no deletion;
   - turn on vulnerability alerts, and confirm the Renovate app is installed (no Renovate PR has
     appeared yet);
   - turn on SHA pinning of actions;
   - turn off the unused wiki and Projects;
   - add `.github/CODEOWNERS` and decide on issue templates.
3. **Keyboard and focus behaviour that players would notice (B7).**
   - The folded header menu stays open when the focus tabs out of it. It should close on focus
     out, and Escape on the Menu button should close it too.
   - When the menu closes for a new `closeKey`, the focus drops to the page. It should return to
     the Menu button.
   - On wide screens the tab order (brand, toggle, nav) differs from what is shown (brand, nav,
     toggle).
   - The kit has no focus style of its own. It relies on the browser's outline, which the nav's
     `overflow-x: auto` clips.
   - The phone chat sheet (`role="dialog"`) does not move the focus in when it opens.
   - The game bar's panel buttons have no `aria-controls`.
   - Targets: the desktop bar buttons are 36 px, and the back link is about 20 px high
     (WCAG 2.5.8 passes on spacing).
   - The phase strip can overflow at 320 px. No viewport in the showcase is 320 px.
   - The contrast check does not test text on the header's `--sidebar-background`. It is
     estimated at about 5.6:1, which passes, but nothing tests it.
4. **API cleanups that are breaking (B4).**
   - `connectCall` and `CALL_SLOT` are exported "for later" (BACKLOG 8). Keep them, or record a
     decision?
   - The server's exported `Headers` type has the name of Node's global `Headers`.
   - `BarIconName` includes the full-screen icons.
   - Prop shapes are uneven: `time?: … | null`, `signIn.signInHref`, the inline `BackLink`
     props, positional versus option arguments, and `useDisclosure`'s unstable callbacks.
     `MenuFold` could be built on `useDisclosure` once those are stable.
5. **CLAUDE.md (B5, B9).** It lists three read-only source repositories but not
   `seasonal-spirits`. It says "only `master` stays on origin" without the night-sheet exception.
   CLAUDE.md changes only with the owner's word.
6. **Legacy recovery codes (from the v0.9.0 review).** Should they get an end date per game?
   This is already in ADOPTION.md.

## Noted, not changed

- **`ThemeToggle` reads `window` while rendering.** So the header cannot be rendered on a
  server. Both games render on the client only (found by the v0.9.0 delivery proof). **Done in
  v0.10.1** (`d3de188`): it renders on a server.
- **Renovate does not update the scanner images' digests.** They sit in `env:` strings. Also,
  `packageManager` has no `+sha512` hash (B6 info). **Done in v0.10.1** (`13ce92a`): a regex
  manager and the hash.
- **`fit.ts` has unnamed tolerances (0.5 px, `> 1`).** The data attributes are partly unprefixed
  (`data-view`, `data-open`). K7 covers classes and keyframes only. `steps.ts` makes a
  `TextDecoder` per call (B3 info). **Done in v0.10.1** (`19eda73`): named constants, `data-sk-`
  attributes (DECISIONS K31), one decoder.
- **The lint config holds `.test.tsx` files and the showcase spec to 300 lines.** That is
  stricter than CLAUDE.md's 400 for tests (B3 info). Still open: not in the v0.10.1 brief.
- **`DevSignIn` does not close on a press outside, unlike `MenuFold`.** It is dev only (B4).
  **Done in v0.10.1** (`ad1171b`): one hook for both.
- **The dev alert names the route id ("player-1"), not the label.** It is dev only (B7 info). **Done in
  v0.10.1** (`ad1171b`).
- **`ChatDock`'s unread count is not announced as it changes (B7 info).** Two `<header>`
  landmarks can coexist; this is moot in focus mode. **Done in v0.10.1** (`4a9ccf8`): a polite
  live region.
- **A refused agent worktree, `.claude/worktrees/agent-a459ae22b757ed187`, and its local branch
  are left in the local checkout.** This session's permissions deny `git worktree`, so it was
  not removed. It is now git-ignored and never on origin.
- **On this machine Vitest's workers sometimes time out while starting under load.** With
  `--maxWorkers=2` every file passes. CI is unaffected.
