## Fixed on the branch

- **No place in the dock.** Every game renders the kit's `DockedScreen`, whose slot took a linked
  call's id only, so the shared view could not sit where the contract puts it ("the same slot").
  `DockedScreen` and `ChatDock` now take `onSharedCall` (K114).
- **The stand-in website** answered 404 to `/embed/call/shared`. It serves the view with nothing
  shared, so a game can prove its wiring.

## Needs the owner

- **A call shared before it starts.** The website's §9 says a game's slot is "hidden until a
  `ready`", and its `ready` may say `scheduled`; the kit shows the slot only while the call is
  live (K77, the website's concept: "hidden while no shared call is live"). Proposal: keep it,
  and have the website's §9 say "until a `ready` with status `live`".
- **A listener loses the sound** when the window crosses the phone breakpoint or the theme
  changes: the view loads anew and waits for **Listen** (BACKLOG 74; a linked call's view does the
  same). Proposal: in a later release keep one frame in the dock and send the view `theme`.
